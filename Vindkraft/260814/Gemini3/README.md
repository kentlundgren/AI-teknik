# Investeringskalkylator för Vindkraftverk (4 MW)

En fristående, interaktiv HTML-kalkylator för vindkraftsinvesteringar, byggd med
**Gemini 3** som ett experiment (daterat 260814 = 2026-08-14) i AI-teknik-repots
samling av AI-genererade verktyg.

Kalkylatorn beräknar nyckeltal som **LCOE**, **nuvärde (NPV)**, **återbetalningstid**
och en **årlig kassaflödessimulering** för ett landbaserat vindkraftverk på 4 MW,
utifrån redigerbara indatafält.
