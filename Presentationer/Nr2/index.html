Hur den här sidan är byggd

Två delar: tekniken i sidan, och metoden jag använde för att ta fram den.

Tekniken

Vanlig HTML, CSS och JavaScript

Inga ramverk, inga bibliotek och inget byggsteg. Sidan består av index.html, style.css, script.js och data.js.

Innehåll skilt från motor

Alla frågor och kort ligger i data.js. script.js bygger sidan av dem, så nya exempel läggs till som en post i datafilen.

Text sätts aldrig som HTML

Innehållet skrivs in med textContent, så en text i datafilen kan inte köra kod.

Ingen data skickas någonstans

Sidan pratar inte med någon server och sparar ingenting om besökaren. Externa länkar öppnas i ny flik med noopener noreferrer.

Frågorna går att länka

Varje fråga har ett eget ankare, till exempel #ai-i-arbetet, och kan nås med tangentbordets vänster- och högerpil.

Fungerar utan JavaScript och på papper

Utan JavaScript visas exemplen som en länklista. Vid utskrift döljs frågeknapparna och korten är utfällda.

Metoden

PRD först

Vad sidan är till för och vem den vänder sig till står i en PRD, PRD_presentation_ai_arbetsgivare.md.

Sedan en låst specifikation

SPEC.md säger exakt hur sidan ska vara, med teckengränser, en sekretesslista och en acceptanslista. Ändringar görs som ny version i ändringsloggen.

Påståenden om hur jag arbetar skrivs in först när jag bekräftat dem. Siffror som är påhittade sägs vara det, och arbeten från uppdrag visas utan länk.
