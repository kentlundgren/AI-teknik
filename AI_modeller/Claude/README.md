# Claude – att förstå och kontrollera Claudes ekosystem

Den här delen av **AI-teknik** samlar projekt om Claude specifikt: hur Anthropics
olika produkter, ytor och styrfiler hänger ihop, och hur man praktiskt jobbar med
dem tillsammans med Cursor och GitHub. Precis som resten av AI-teknik-projektet
är målet pedagogiska och styrande dokument snarare än en statisk manual — det
här ändrar sig fort, och delarna byggs och skrivs om i takt med det.

## Projekt i den här mappen

- **[olika_Claude_modeller/](./olika_Claude_modeller/)** — bloggtext och
  interaktivt verktyg ("Claude-kompassen") om Claudes tre faser: filerna som
  styr samarbetet (CLAUDE.md/AGENTS.md/SKILL.md), ytorna man väljer att jobba i,
  och vägen vidare via Cursor och Git till GitHub.
  Se [`olika_Claude_modeller/README.md`](./olika_Claude_modeller/README.md) för
  en utförlig beskrivning.
  **Live-sida (GitHub Pages):**
  https://kentlundgren.github.io/AI-teknik/AI_modeller/Claude/olika_Claude_modeller/
  **Bloggtext:**
  [En bild av Claudes ekosystem](https://klel.wordpress.com/2026/07/29/en-bild-av-claudes-ekosystem/)
